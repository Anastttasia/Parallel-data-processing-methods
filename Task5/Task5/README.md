**Результаты работы**
- `ConcurrentDictionary` немного быстрее синхронизации `Dictionary` с помощью `ReaderWriterLockSlim`
- `TaskQueueManager` не гарантирует 100% выполнение задач
- `ConcurrentCache` не гарантирует 100% успешность операций

**Как всё работает:**

**Program.cs:** главый файл, который является точкой входа в программу.

- Инициализирует все необходимые переменные: `seed` (зерна случайных чисел), `booksCount` (количество первоначально сгенерированных книг для `LibraryCatalog` и `ConcurrentLibraryCatalog`), `queueManagerCapacity` (размер очереди `TaskQueueManager`), также генерирует первоначальные данные для `LibraryCatalog` и `ConcurrentLibraryCatalog`, создаёт `benchmark` (объект для тестирования - инстанс класса `CollectionBenchmark`).
- С помощью метода `CompareAllCollections` выводит в консоль всю информацию о результатах тестирования.

**LibraryCatalog.cs:** файл с одноимённым классом каталога библиотеки с различными методами синхронизации.

- `_catalog` - словарь (тип `Dictionary`) для хранения данных о книгах.
- `_locker` - объект типа `ReaderWriterLockSlim`

- `AddBook` - реализует потокобезопасный метод добавления данных о книге;
- `RemoveBook` - реализует потокобезопасный метод удаления данных о книге;
- `UpdateBook` - реализует потокобезопасный метод обновления данных о книге;

- `SearchBooks` - реализует потокобезопасный метод поиска всех книг в каталоге по заданному ключевому слову `keyword`;
- `GetAllBooks` - реализует потокобезопасный метод получения информации о всех книгах в каталоге;

- `TryAddBook` - реализует потокобезопасный метод добавления данных о книге с помощью `Monitor` с таймаутом `timeoutMs`;
- `TrySearchBooks` - реализует потокобезопасный метод поиска всех книг в каталоге по заданному ключевому слову `keyword` с помощью `Monitor` с таймаутом `timeoutMs`;


**ConcurrentLibraryCatalog.cs:** файл с одноимённым классом каталога библиотеки с использованием `ConcurrentDictionary`.
(Также внутри хранится класс `Book` - обёртка для информации о книгах)

- `Books` - словарь (тип `ConcurrentDictionary`) для хранения данных о книгах.

- `AddBook` - реализует потокобезопасный метод добавления данных о книге;
- `RemoveBook` - реализует потокобезопасный метод удаления данных о книге;
- `UpdateBook` - реализует потокобезопасный метод обновления данных о книге;

- `SearchBooks` - реализует потокобезопасный метод поиска всех книг в каталоге по заданному ключевому слову `keyword`;
- `GetAllBooks` - реализует потокобезопасный метод получения информации о всех книгах в каталоге;

- `GetBookCount` - возращает количество книг в каталоге;
- `ClearCatalog` - реализует очистку каталога;
- `TryGetBook` - реализует потокобезопасный метод получения одной книги из каталога по названию `title` (возвращаемое значение помещается с помощью `out` аргумента book (тип `Book`);

**TaskQueueManager.cs:** файл с одноимённым классом для управления очереди задач с использованием `BlockingCollection`.
(Также внутри хранится класс `TaskItem` - обёртка для хранения задачи Action с типом `Action`)

- `TaskQueue` - коллекция очереди задач (тип `BlockingCollection<TaskItem>`)

- `TaskQueueManager(int boundedCapacity)` - конструктор, где `boundedCapacity` размер очереди для коллекции `TaskQueue`;

- `AddTask` - добавление задачи в очередь --- входные аргументы (`string description` - описание задачи, `Action taskAction` - задача для хранения);
- `ProcessTasks` - исполняет все задачи, которые хранятся в коллекции `TaskQueue`;
- `CompleteAdding` - блокирует добавление новых задач в коллекцию `TaskQueue`;
- `GetPendingTaskCount` - возвращает размер очереди задач `TaskQueue`;

**ConcurrentCache.cs:** файл с одноимённым классом класс кэша с использованием `ConcurrentDictionary` и `ConcurrentBag`.
(Также внутри хранится класс `CacheItem` - обёртка для хранения объектов в кэше)

- `Cache` - словарь (тип `ConcurrentDictionary`) для хранения объектов.

- `AddToCache` - пытается добавить объект в словарь `Cache`, возвращает была ли успешна операция (тип `bool`);
- `TryGetFromCache` - пытается взять объект из словаря `Cache`, возвращает была ли успешна операция (тип `bool`);
- `RemoveFromCache` - пытается удалить объект из словаря `Cache`, возвращает была ли успешна операция (тип `bool`);
- `GetCacheSize` - возвращает размер кэша `Cache`;
- `ClearCache` - очищает кэш `Cache`;

**SynchronizationBenchmark.cs:** файл с одноимённым классом для сравнения производительности разных примитивов.

- `BenchmarkSynchronizedDictionary` - тестирует каталог `LibraryCatalog`, возвращает кортеж с временем выполнения и количеством успешных операций.
- `BenchmarkConcurrentDictionary` - тестирует каталог `ConcurrentLibraryCatalog`, возвращает кортеж с временем выполнения и количеством успешных операций.
- `BenchmarkBlockingCollection` - тестирует очередь задач `TaskQueueManager`, возвращает кортеж с временем выполнения и количеством успешных операций.
- `BenchmarkConcurrentCache` - тестирует каталог `ConcurrentCache`, возвращает кортеж с временем выполнения и количеством успешных операций и количества неуспешных операций.
- `CompareAllPrimitives` - проводит тестирование всех всех коллекций и выводит результаты тестирования на экран.
