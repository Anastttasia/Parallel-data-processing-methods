**Как всё работает:**

**Program.cs:** главый файл, который является точкой входа в программу.

- Инициализирует все необходимые переменные: `seed` (зерна случайных чисел), `arraySize` (количество чисел для генерации и обработки), `transferCount` (количества транзакций), также генерирует числа для изначального массива, создаёт `benchmark` (объект для тестирования - инстанс класса `SynchronizationBenchmark`).
- С помощью метода `CompareAllApproaches` выводит в консоль всю информацию о результатах тестирования.

**BankAccount.cs:** файл с одноимённым классом, содержащим методы обработки данных.

- `Balance` - свойство, которое хранит текущий баланс
- `_lock` - объект типа `Lock`
- `_monitorObj` - объект пустышка для работы с `Monitor`

- `Deposit` - реализует небезопасный метод пополнения счёта;
- `Withdraw` - реализует небезопасный метод снятия средств счёта;
- `Transfer` - реализует небезопасный метод перевода средств с текущего счёта на счёт получателя;

- `DepositWithLock` - реализует потокобезопасный метод пополнения счёта (обеспечавает потокобезопасность с помощью захвата `Lock`);
- `WithdrawWithLock` - реализует потокобезопасный метод снятия средств счёта (обеспечавает потокобезопасность с помощью захвата `Lock`);
- `TransferWithLock` - реализует потокобезопасный метод перевода средств с текущего счёта на счёт получателя (обеспечавает потокобезопасность с помощью захвата `Lock` у отправителя и получателя);

- `DepositWithMonitor` - реализует потокобезопасный метод пополнения счёта (обеспечавает потокобезопасность с помощью захвата `Monitor`);
- `WithdrawWithMonitor` - реализует потокобезопасный метод снятия средств счёта (обеспечавает потокобезопасность с помощью захвата `Monitor`);
- `TransferWithMonitor` - реализует потокобезопасный метод перевода средств с текущего счёта на счёт получателя (обеспечавает потокобезопасность с помощью захвата `Monitor` у отправителя и получателя);

- `DepositWithTimeout` - реализует потокобезопасный метод пополнения счёта (обеспечавает потокобезопасность с помощью таймера для попытки захватить `Monitor`);
- `WithdrawWithTimeout` - реализует потокобезопасный метод снятия средств счёта (обеспечавает потокобезопасность с помощью таймера для попытки захватить `Monitor`);

**TransactionProcessor.cs:** файл с одноимённым классом, содержащим методы обработки данных.

- `ProcessTransactionsConcurrently` - реализует потокоНЕбезопасное выполнение транзакций между банковскими счетами. Возращает итоговый баланс. (Если были переданы неверные данные, то возвращает `0.0`)
- `ProcessTransactionsWithLock` - реализует потокобезопасное выполнение транзакций между банковскими счетами с помощью захвата `Lock`. Возращает итоговый баланс. (Если были переданы неверные данные, то возвращает `0.0`)
- `ProcessTransactionsWithMonitor` - реализует потокобезопасное выполнение транзакций между банковскими счетами с помощью захвата `Monitor`. Возращает итоговый баланс. (Если были переданы неверные данные, то возвращает `0.0`)
- `ProcessConcurrentTransfers` - реализует потокобезопасное выполнение транзакций между банковскими счетами с помощью таймера на захват `Monitor`. Возвращает наличие взаимоблокировок. (Если были переданы неверные данные, то возвращает `false`)

**SynchronizationBenchmark.cs:** файл с одноимённым классом, содержащим методы измерения времени выполнения и корректности финальных данных.

- `BenchmarkNoSync` - реализует измерение времени работы потокоНЕбезопасных переводов. Принимает на вход ссылку на аккаунт `account` (тип `BankAccount`) и список проводимых операций `transactions` (тип `List<decimal>`). Создаёт `Stopwatch` (счётчик времени) и вызывает `TransactionProcessor.ProcessTransactionsConcurrently`. Останавливает таймер и возвращает кортеж со временем выполнения `stopwatch.Elapsed`, результирующим балансом `resultBalance`, сравнением баланса получателя и отправителя `(resultBalance + account.GetBalance()) == 0)`.
- `BenchmarkWithLock` - реализует измерение времени работы покотобезопасных переводов (обеспечавает потокобезопасность с помощью захвата `Lock`). Принимает на вход ссылку на аккаунт `account` (тип `BankAccount`) и список проводимых операций `transactions` (тип `List<decimal>`). Создаёт `Stopwatch` (счётчик времени) и вызывает `TransactionProcessor.ProcessTransactionsWithLock`. Останавливает таймер и возвращает кортеж со временем выполнения `stopwatch.Elapsed`, результирующим балансом `resultBalance`, сравнением баланса получателя и отправителя `(resultBalance + account.GetBalance()) == 0)`.
- `BenchmarkWithMonitor` - реализует измерение времени работы покотобезопасных переводов (обеспечавает потокобезопасность с помощью захвата `Monitor`). Принимает на вход ссылку на аккаунт `account` (тип `BankAccount`) и список проводимых операций `transactions` (тип `List<decimal>`). Создаёт `Stopwatch` (счётчик времени) и вызывает `TransactionProcessor.ProcessTransactionsWithMonitor`. Останавливает таймер и возвращает кортеж со временем выполнения `stopwatch.Elapsed`, результирующим балансом `resultBalance`, сравнением баланса получателя и отправителя `(resultBalance + account.GetBalance()) == 0)`.
- `CompareAllApproaches` - проводит тестирование всех методов переводов и выводит результаты тестирования на экран.
