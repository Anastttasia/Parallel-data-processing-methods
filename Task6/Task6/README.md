**Результаты работы**
- `AtomicCounter` существенно быстрее `LockCounter`

**Как всё работает:**

**Program.cs:** главый файл, который является точкой входа в программу.

- Инициализирует `benchmark` (тип `AtomicBenchmark`)
- С помощью метода `CompareAllApproaches` выводит в консоль всю информацию о результатах тестирования.

**LockCounter.cs:** файл с одноимённым классом потокобезопасного (за счёт использования `lock`) счётчика.

- `realValue` - текущее значение счётчика.
- `_lockObj` - объект типа `Lock` объект заглушка для использования `lock`

- `Increment` - увеличиывает значение счётчика на 1;
- `Decrement` - уменьшает значение счётчика на 1;

- `Add` - добавляет к счётчику значение аргумента (`value`);
- `Exchange` - заменяет значение счётчика значеним аргумента (`value`);
- `CompareExchange` - если текущее значение счётчика равно переданному значению для сравнения (`comparand`), то заменяет значение счётчика значеним аргумента (`value`);

- `Reset` - выставляет значение счётчика в 0;
- `GetAndIncrement` - увеличиывает значение счётчика на 1 и возвращает его;
- `GetAndDecrement` - уменьшает значение счётчика на 1 и возвращает его;


**AtomicCounter.cs:** файл с одноимённым классом потокобезопасного (за счёт использования `Interlocked` операций) счётчика.

- `realValue` - текущее значение счётчика.
- `_lockObj` - объект типа `Lock` объект заглушка для использования `lock`

- `Increment` - увеличиывает значение счётчика на 1;
- `Decrement` - уменьшает значение счётчика на 1;

- `Add` - добавляет к счётчику значение аргумента (`value`);
- `Exchange` - заменяет значение счётчика значеним аргумента (`value`);
- `CompareExchange` - если текущее значение счётчика равно переданному значению для сравнения (`comparand`), то заменяет значение счётчика значеним аргумента (`value`);

- `Reset` - выставляет значение счётчика в 0;
- `GetAndIncrement` - увеличиывает значение счётчика на 1 и возвращает его;
- `GetAndDecrement` - уменьшает значение счётчика на 1 и возвращает его;

**LockFreeStack.cs:** файл с одноимённым классом реализующим потокобезопасные стэк.
(Также внутри хранится класс `Node` - обёртка для хранения объектов в стэке)

- `_head` - текущая вершина стэка (тип `Node`)

- `Push` - положить значение `item` в стэк;
- `TryPop` - вытащить верхнее значение из стэка (также убирая его из стэка);
- `TryPeek` - вытащить верхнее значение из стэка (не убирая его из стэка);
- `IsEmpty` - пуст ли стэк;
- `Clear` - очистка стэка;

**StatisticsTracker.cs:** файл с одноимённым классом для сбора статистики с атомарными операциями.

- `TotalRequests` - коллекция очереди задач (тип `AtomicCounter`)
- `SuccessfulRequests` - коллекция очереди задач (тип `AtomicCounter`)
- `FailedRequests` - коллекция очереди задач (тип `AtomicCounter`)
- `TotalProcessingTime` - коллекция очереди задач (тип `AtomicCounter`)

- `RecordRequest` - запись статистики запроса;
- `GetSuccessRate` - расчет процента успешных запросов;
- `GetAverageProcessingTime` - расчет среднего времени обработки;
- `GetSuccessCount` - возвращает количество успешных запросов;
- `Reset` - сброс всех счетчиков;

**ConcurrentCache.cs:** файл с одноимённым классом класс кэша с использованием `ConcurrentDictionary` и `ConcurrentBag`.
(Также внутри хранится класс `CacheItem` - обёртка для хранения объектов в кэше)

- `Cache` - словарь (тип `ConcurrentDictionary`) для хранения объектов.

- `AddToCache` - пытается добавить объект в словарь `Cache`, возвращает была ли успешна операция (тип `bool`);
- `TryGetFromCache` - пытается взять объект из словаря `Cache`, возвращает была ли успешна операция (тип `bool`);
- `RemoveFromCache` - пытается удалить объект из словаря `Cache`, возвращает была ли успешна операция (тип `bool`);
- `GetCacheSize` - возвращает размер кэша `Cache`;
- `ClearCache` - очищает кэш `Cache`;

**AtomicBenchmark.cs:** файл с одноимённым классом для сравнения.

- `BenchmarkInterlockedCounter` - тестирует счётчик `AtomicCounter`, возвращает кортеж с временем выполнения, значением счётчика и корректностью данных.
- `BenchmarkInterlockedCounter` - тестирует счётчик `LockCounter`, возвращает кортеж с временем выполнения, значением счётчика и корректностью данных.
- `BenchmarkLockFreeStack` - тестирует стэк `LockFreeStack`, возвращает кортеж с временем выполнения, количеством успешных операций и корректностью данных.
- `CompareAllApproaches` - проводит тестирование общее тестирование и выводит результаты на экран.
