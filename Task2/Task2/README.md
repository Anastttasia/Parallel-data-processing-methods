**Результаты работы**
- Удалось добиться среднего ускорения вычислений в 3 раза при 10,000,000 числел и 4х потоках.
- Удалось добиться среднего ускорения вычислений в 5 раз при 10,000,000 числел и использовании `ThreadPool`.
- TAP обработка по времени примерно равна последовательной.

**Как всё работает:**

**Program.cs:** главый файл, который является точкой входа в программу.

- Инициализирует все необходимые переменные: `seed` (зерна случайных чисел), `arraySize` (количество чисел для генерации и обработки), `threadsCount` (количества потоков), также генерирует числа для изначального массива, создаёт `processor` (обработчик данных - инстанс класса `DataProcessor`) и `processorNew` (обработчик данных - инстанс класса `TaskProcessor`).
- С помощью метода `MeasureExecutionTime` из `PerformanceMeter` получает данные о времени выполнения `ProcessSequential` (последовательной), `ProcessParallel` (параллельной) обработки данных, `ProcessThreadPool` (ThreadPool обработка), `ProcessAsync` (TAP обработки).
- Выводит в консоль всю информацию.

**TaskProcessor.cs:** файл с одноимённым классом, содержащим методы обработки данных.

- `ProcessDataWithThreadPool` - реализует параллельную обработку данных с помощью `ThreadPool` (пула потоков). Разбивает изначальных массив на 8 частей и создаёт 8 задач для `ThreadPool`. Ожидает их завершения с помощью `CountdownEvent` и возвращает полученный массив. (Если были переданы неверные данные, то возвращает `null`)
- `ProcessDataAsync` - реализует асинхронную обработку данных на основе шаблона TAP (Task-based Asynchronous Pattern). Принимает на вход копию массива данных и создаёт `Task` (асинхронную задачу) и возвращает её. (Если были переданы неверные данные, то в результат работы задачи попадёт `null`) 
- `ProcessDataWithAPM` - реализует асинхронную обработку данных на основе шаблона APM (Asynchronous Programming Model)
- `RealProcessData` - реализует саму формулу рассчёта обработки изначальных данных. Принимает на вход ссылку на массив, в котором лежит копия изначальных чисел и проводит рассчёты, перезаписывая изначальные значения.

**DataProcessor.cs:** файл с одноимённым классом, содержащим методы обработки данных.

- `ProcessSequential` - реализует последовательную обработку данных. Принимает на вход копию массива данных. Создаёт новый массив для возрата и передаёт его в метод RealProcessData, после чего возращает его. (Если были переданы неверные данные, то возвращает `null`)
- `ProcessParallel` - реализует параллельную обработку данных. Принимает на вход копию массива данных и количество потоков. После чего разбивает изначальных массив на части (по количеству потоков) и копирует в них части данных из изначального массива. Создаёт потоки которые вызывают метод `RealProcessData` и копируют полученные данные в финальный массив. Ожидает завершения потоков с помощью `CountdownEvent` и возвращает получившийся массив. (Если были переданы неверные данные, то возвращает `null`)
- `RealProcessData` - реализует саму формулу рассчёта обработки изначальных данных. Принимает на вход ссылку на массив, в котором лежит копия изначальных чисел и проводит рассчёты, перезаписывая изначальные значения.

**PerformanceMeter.cs:** файл с одноимённым классом, содержащим методы измерения времени выполнения и корректности финальных данных.

- `MeasureExecutionTime` - реализует измерение времени работы методов обработки данных. Принимает на вход ссылку на метод, время работы которого необходимо измерить. Создаёт `Stopwatch` (счётчик времени) и вызывает переданный `action` (метод обработки данных). Останавливает таймер и возвращает результирующий массив и время выполнения.
- `CompareResults` - реализует проверку корректности вычислений. Принимает на два массива и сравнивает все значения на заданную `tolerance` (точность), если все числа соответсвуют ей, то возвращает `true`. (Если переданы неправильные аргументы или данные в массивах расходятся возвращает `false`)
