**Как всё работает:**

**Program.cs:** главый файл, который является точкой входа в программу.

- Инициализирует все необходимые переменные: `seed` (зерна случайных чисел), `booksCount` (количество первоначально сгенерированных книг для `LibraryCatalog`), `resourcePoolCapacity` (количество доступных ресурсов в `ResourcePool`), также генерирует первоначальные данные для `LibraryCatalog`, создаёт `benchmark` (объект для тестирования - инстанс класса `SynchronizationBenchmark`).
- С помощью метода `CompareAllPrimitives` выводит в консоль всю информацию о результатах тестирования.

**LibraryCatalog.cs:** файл с одноимённым классом каталога библиотеки с различными методами синхронизации.

- `_catalog` - словарь (тип `Dictionary`) для хранения данных о книгах.
- `_locker` - объект типа `ReaderWriterLockSlim`

- `AddBook` - реализует потокобезопасный метод добавления данных о книге;
- `RemoveBook` - реализует потокобезопасный метод удаления данных о книге;
- `UpdateBook` - реализует потокобезопасный метод обновления данных о книге;

- `SearchBooks` - реализует потокобезопасный метод поиска всех книг в каталоге по заданному ключевому слову `keyword`;
- `GetAllBooks` - реализует потокобезопасный метод получения информации о всех книгах в каталоге;

- `TryAddBook` - реализует потокобезопасный метод добавления данных о книге с помощью `Monitor` с таймаутом `timeoutMs`;
- `TrySearchBooks` - реализует потокобезопасный метод поиска всех книг в каталоге по заданному ключевому слову `keyword` с помощью `Monitor` с таймаутом `timeoutMs`;

**ResourcePool.cs:** файл с одноимённым классом для управления пулом ограниченных ресурсов.

- `_pool` - стэк для ресурсов (тип `ConcurrentStack`)
- `_sync` - объект типа `SemaphoreSlim`
- `_maxResources` - максимальное количество ресурсов

- `AvailableCount` - свойство возвращающее доступное количество ресурсов в пуле;

- `AcquireResource` - реализует потокобезопасный метод получения ресурса с помощью примитива `SemaphoreSlim`;
- `ReleaseResource` - реализует потокобезопасный метод возврата ресурса с помощью примитива `SemaphoreSlim`;
- `TryAcquireResource` - реализует потокобезопасный метод получения ресурса с помощью примитива `SemaphoreSlim` с задержкой захвата `timeoutMs`;


**CrossProcessSync.cs:** файл с одноимённым классом для межпроцессной синхронизации.

- `ExecuteWithGlobalLock` - реализует потокобезопасное выполнение действия `action` (тип `Action`) с помощью примитива `Mutex`.
- `TryExecuteWithGlobalLock` - реализует потокобезопасное выполнение действия `action` (тип `Action`) с помощью примитива `Mutex` с таймаутом на захват `timeoutMs`. Возращает был ли выполнено действие.

**SynchronizationBenchmark.cs:** файл с одноимённым классом для сравнения производительности разных примитивов.

- `BenchmarkReaderWriterLock` - реализует измерение времени работы примитива синхронизации `ReaderWriterLockSlim`. Принимает на вход ссылку на каталог `library` (тип `LibraryCatalog`) и количества операций чтения `readerCount` и записи `writerCount`. Создаёт `Stopwatch` (счётчик времени) для записи и чтения отдельно и создаёт потоки для моделирования чтения и записи в каталог, также создаёт данные для записи (`author` и `title`). Останавливает таймер и возвращает кортеж со временем чтения `readerTime`, временем записи `writerTime`, и общим временем `(readerTime + writerTime)`.
- `BenchmarkSemaphore` - реализует измерение времени работы примитива синхронизации `SemaphoreSlim`. Принимает на вход ссылку на пул ресурсов`pool` (тип `ResourcePool`) и количество запросов `requestCount`. Создаёт `Stopwatch` (счётчик времени) и создаёт потоки для моделирования запросов. Останавливает таймер и возвращает кортеж со временем выполнения `stopwatch.Elapsed`, количеством успешных операций `succesed`, количеством неуспешных операций `failed`.
- `BenchmarkMutex` - реализует измерение времени работы примитива синхронизации `Mutex`. Принимает на вход ссылку на объект межпроцессной синхронизации `syncer` (тип `CrossProcessSync`) и количество операций `operationCount`. Создаёт `Stopwatch` (счётчик времени) и создаёт потоки для моделирования операций. Останавливает таймер и возвращает кортеж со временем выполнения `stopwatch.Elapsed`, количеством успешных операций `succesed`.
- `CompareAllPrimitives` - проводит тестирование всех примитивов синхронизации и выводит результаты тестирования на экран.  Принимает на вход ссылку на каталог `library` (тип `LibraryCatalog`), ссылку на пул ресурсов`pool` (тип `ResourcePool`) , и ссылку на объект межпроцессной синхронизации `syncer` (тип `CrossProcessSync`)
